# Sigil-Enhanced 2.8.6E15 更新说明

源码发布日期为 2026 年 11 月 22 日。安装包发布日期以发布页面为准。

## Agent 内置翻译

- 在 Agent 对话里指定目标语言和范围即可翻译当前打开的 EPUB，包括尚未保存的编辑。默认在原文后添加译文，保留原文、链接、ID 和 ruby。可以先试译选区、单章或所选文件，也可以让 Agent 对全书扫描、汇总术语、分批翻译和校正。选区会扩展到完整阅读段落。
- 后台任务卡会显示当前阶段、已扫描和写入的数量、活动请求、排队和重试，可暂停、继续或重试未完成的部分。可单独执行翻译、校正或格式整理，已完成的内容会保留。
- 翻译复用 Agent 的连接设置，可在「应用程序设置 → 原生 Agent → 翻译」单独选择模型、思考程度和并发数。默认并发为 4，网络断开、超时或限流等临时错误最多自动重试 5 次。限流后会降低并发，端点恢复后逐步提速。
- 计划、临时术语和缓存按会话隔离。已经写入书籍的译文可通过正常保存保留，术语表也可以保存到书里的 Misc，供之后导入。[使用说明](https://github.com/3tic-project/Sigil-Enhanced/blob/v2.8.6E15/docs/BuiltinTranslation.md)
- 修复对话内容落后一个工具卡片才滚动的问题。后台工具刷新书籍时会保留其他窗口的焦点。

## 搜索与窗口

- 搜索栏位于编辑器下方。普通和增强模式命中后都会把焦点交给代码视图，跨文件定位后也能直接输入修改。修复搜索栏展开时面板标题重叠，以及拉宽预览后重开窗口压缩书籍浏览器的问题。
- 可在「设置 → 编辑器 → 代码视图 → 查找和替换模式」关闭「批量全部替换前创建检查点」。默认开启，适用于增强模式跨文件全部替换和已保存搜索的批量替换。关闭后仍可撤销各文件的文本修改。[搜索与窗口行为](https://github.com/3tic-project/Sigil-Enhanced/blob/v2.8.6E15/docs/SearchAndWindowState.md)
- 打开 EPUB 的警告和错误在窗口布局恢复后显示。弹窗导致窗口退出最大化或全屏时，关闭弹窗后会恢复原状态。
- 关闭书籍后，解包文件在后台删除，其他书籍窗口可继续编辑。仍被占用的临时文件会重试清理。

## 稳定性和上游修复

- 通过文件选择框覆盖同名字体时，更新原资源的内容并保留清单和资源身份。修复 XHTML 添加副本后立即重命名时的卡死。
- 修复目录编辑、词典重载、Python 错误提示和 Agent 会话中的锁或资源访问问题。关闭目标编辑页后，加载或简繁转换的延迟回调会安全结束，关闭全部编辑页后仍可在全书范围搜索和替换。[反馈修复和验证范围](https://github.com/3tic-project/Sigil-Enhanced/blob/v2.8.6E15/docs/WindowsE14FeedbackFixes.md)
- 同步上游对 Lexbor 的修复，保留 CSS 选择器中的数字写法和声明的 `!important`。修复校验插件处理书籍路径时的编码问题，并保留数值字符引用。[上游改动](https://github.com/3tic-project/Sigil-Enhanced/pull/20)

## 下载和验证

- 发布页提供 Windows x64 安装程序、macOS Intel 和 Apple 芯片安装镜像，以及 `SHA256SUMS.txt` 校验文件。
- macOS 回归覆盖 Agent 翻译、字体覆盖、XHTML 副本重命名、窗口布局与搜索、锁重入和资源生命周期。Windows 10 原生文件选择框及独立进程间的响应仍待实机复测。
