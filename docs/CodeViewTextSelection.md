# 代码视图文本选择

Sigil-Enhanced 的 XHTML 代码视图可以让双击直接选中当前正文单元的内部源码，
也可以只选择当前句子。这适合中文、日文，以及包含 Ruby、实体或多个行内标签的
段落：选区不会把内部标记截成两半。

例如，在下面的 Ruby 基字或注音上双击：

```html
<p>春天的<ruby>風<rt>かぜ</rt></ruby>，很轻。</p>
```

得到的选区是：

```html
春天的<ruby>風<rt>かぜ</rt></ruby>，很轻。
```

选择操作只改变编辑器选区，不修改 XHTML，不新增 undo/redo 步，也不改变书籍的
modified 状态。

## 设置

入口为“偏好设置 → 编辑器 → 代码视图 → 双击选择”。

| 模式 | 行为 |
|---|---|
| 当前段落/标签内容 | 默认值；选择最近正文单元的内部源码 |
| 当前句子 | 按可见文字的 Unicode 句子边界选择，并映射回原始 XHTML |
| 字或词（原有行为） | 恢复 Qt 双击加 Unicode `\w+` 收窄的原有选择方式 |

设置会写入本机 Sigil 首选项，立即供所有 XHTML 代码编辑器读取；同一分屏中的两个
编辑器使用相同模式。不存在或无法识别的旧设置会安全恢复为默认模式。

## 选择规则

正文单元包括 `p`、`h1`–`h6`、`li`、`dt`、`dd` 和没有结构性块后代的叶子
`div`。直接承载文字且没有内部段落的 `blockquote` 也可作为一个单元。

- 双击正文或其 `span`、`em`、`a`、`ruby`、`rt` 等行内后代时，选择最近的正文单元；
- 选区保留换行、缩进、实体写法与所有内部标签；
- 普通双击标签名、属性名或属性值仍使用原有词选择；
- Ctrl/Command 修饰的双击不启用正文扩选；
- Shift 双击标签继续选择标签内部源码；
- Alt/Option 双击标签继续选择包含起止标签的完整元素；
- 正文处的右键菜单提供“选择元素内容”和“选择整个元素”，方便键盘与辅助操作流程。

“当前句子”模式先投影正文单元的可见文字，再用 Unicode 句子边界识别中文、日文、
小数、网址和尾随引号。数字实体与常见命名实体在投影中解码，但选区映射回源码后仍
保留原实体拼写；句子完整覆盖 `span`、`em`、`ruby` 等行内元素时，会把成对标签一并
保留。若句子只包含起始或结束标签的一侧，则安全回退到整个正文单元，避免得到不平衡
的源码选区。

为了避免误选整章或破坏源码，以下位置回退为原有词选择：

- `pre`、`code`、`script`、`style`、SVG 和 MathML 内部；
- 注释、CDATA、标签与属性范围；
- 未闭合或无法可靠配对的标签；
- 纯空白正文单元、`img`、`br` 等空元素；
- 含标题、段落、列表等结构块后代的章节容器或复杂列表项。

句子模式还会对包含 `pre`、`code`、`script`、`style`、SVG 或 MathML 后代的整个正文
单元保守回退。一次边界计算只投影点击点两侧各 65,536 个 UTF-16 code units；如果一个
异常长句跨出窗口且无法可靠确定边界，则回退为原有词选择。此限制不会截取一个猜测的
句子，也不会修改文档。

位置与 Qt 编辑器一致使用 UTF-16 code units，因此 emoji、扩展汉字和组合字符不会
让元素边界偏移。Preview DOM 选择不属于当前交付范围。

## 工程结构与性能

`CodeViewSelectionPolicy` 是不依赖 QWidget 的范围计算层。它复用编辑器已有的
`TagLister` 索引，返回内部范围、完整元素范围和明确的回退原因；
`CodeViewEditor` 只负责从真实鼠标坐标取得 UTF-16 位置并应用 `QTextCursor`。

索引在文档变更后失效，并在下一次需要标签信息时重建。暖索引性能回归用例包含
20,000 个段落并连续采样 20 次，段落和句子模式都硬性要求 P95 不高于 50 ms；
含 2,000 个行内标签的句子和 1 MiB 正文末尾句子要求不高于 100 ms。冷索引路径只
提取一次文档文本，再同时用于重建索引和计算选区；跨平台 Release 构建仍需复测。

## 测试

```sh
ctest --test-dir build \
  -R '^(code_view_selection_policy|code_view_selection_integration)$' \
  --output-on-failure
```

纯策略测试覆盖中文、日文、Ruby、数字和命名实体、小数、网址、尾随引号、部分/完整
行内标签、同一行相邻元素、多行缩进、复杂列表、危险容器、不良构源码、UTF-16、
超长句回退和大文档性能。macOS Ninja Debug 下的原生集成测试复用真实 Sigil 应用
对象，覆盖实际鼠标坐标、三种设置值、设置页、分屏同策略、Shift/Alt/Ctrl、属性与
非 XHTML 回退、右键动作，以及选择不污染文档和 undo 栈。
