# Sigil-Enhanced 2.8.1E7 更新说明

发布日期：2026 年 8 月 9 日。

本文记录 `2.8.1E7` 相对上一个发布版本 `v2.8.1E6` 的主要变化。比较基线为
`v2.8.1E6`（`873876cd6`）。

## 重点更新

### 高级正则工作台

- 在“增强”菜单加入独立的高级正则工作台，支持二级正则筛选、受限递归替换和命名捕获变量。
- 规则支持“仅捕获”，可以只把命名捕获写入会话变量而不修改正文；后续规则可在替换文本中引用这些变量。
- 支持可保存的版本化 Recipe、Dry Run、应用前暂存 XML 校验、取消运行及 Automate 调用。
- Dry Run 结果可双击跳到对应文件和行，并在报告基线仍有效时高亮精确位置。
- 工作台改为独立的非模态顶层窗口，标题同步当前 EPUB；打开工作台时仍可切回 Sigil 编辑器查找和核对正文。
- 作用范围覆盖当前文件、Book Browser 选中文件、全部 XHTML、全部 CSS、OPF/NCX/SVG/XML 等特殊文本文件及全部文本资源。

详细用法见 [高级正则工作台](AdvancedRegexWorkbench.md)。

### 搜索模板批处理性能与可靠性

- 普通版和增强版的保存搜索批处理先在内存中按规则顺序暂存，整批成功后再统一写回。
- 同一批处理中每个有变化的资源只写回一次，避免每条规则都触发文档重载、渲染、Preview 刷新和全书写盘。
- 批次最多创建一个非变异恢复检查点；暂存 XML、资源快照或提交后置条件失败时，不发布部分结果。
- 已写入资源会在提交失败时逆序回滚；Automate 会收到失败并停止，不再把失败批次记为已完成。
- 普通、Plus、Python 函数替换和批量暂存写回均保留 Code View 撤销历史；每个成功资源写入对应一个撤销步骤。
- 查找替换进度更新不再接收递归按钮点击或关闭主窗口输入，修复跨文件 Plus Replace All 期间可能发生的崩溃。

实现边界与审计记录见
[搜索模板批处理优化审计](SearchTemplateBatchOptimizationAuditDesign.md)。

### 段落规范化工具

- 新增 BookLive/EBPAJ Div 段落分析与规范化，将安全识别的 `div` 伪段落原位转换为语义化 `p`。
- BookLive 转换保留原 class、inline style、布局 wrapper、纵排、ruby、锚点、插图和空行；复杂页面默认跳过并要求人工复核。
- Kobo BR、Kindle KFX 与 BookLive 三组菜单现在统一明确标注“当前文件”或“全书”；分析入口也明确为全书扫描。
- 当前文件操作尽量保留单步撤销；全书操作只处理 auto-safe 页面，并在写回前建立 Checkpoint。

### 上游同步与界面修复

- 同步 Sigil 2.8.1 后续修复，并集成项目内固定版本的 Lexbor CSS parser 与相关解析器更新。
- 修复全新 Windows/macOS 打包构建无法找到生成的 PCRE2 头文件，以及 Windows 链接阶段残留未实现构造函数引用的问题。
- 编辑标签栏支持使用鼠标中键关闭所指向的标签页，空白区域不会触发关闭。
- 改进 Book Browser 全量刷新和非连续选择拖拽，合并重复 manifest 路径警告，并补充 JXL/AVIF 媒体类型处理。
- 图片悬停预览会限制在可用屏幕内；macOS 在所有窗口不可见时点击 Dock 图标会重新打开主窗口。
- 修复旧版“日文引号纠正”搜索模板的兼容迁移，避免旧替换语法生成无效 XML 名称。
- 修复 Sigil 直接构建目标的资源依赖，IDE 的 Build Before Run 可以可靠生成图标、翻译和其它必需资源。

## 兼容性说明

- 保存搜索、快捷键 action ID 与 Automate 命令名称保持不变；段落工具只调整用户可见名称和范围提示。
- 旧高级搜索模板可继续加载；已知的旧日文引号模板会在载入时迁移。
- 高级正则 Recipe 使用独立的版本化 JSON，不会覆盖已有保存搜索文件。
- 全书批处理的跨资源恢复仍以 Checkpoint 为准；Code View 撤销栈按资源维护，不提供跨多个文件的一次全局 Undo。

## 验证范围

- Debug Sigil 应用完整编译、链接及内置 Python 包校验。
- CTest 覆盖搜索暂存/回滚、撤销、BookLive 规范化、高级正则核心与 UI 契约、EPUB 样本和三语翻译完整性。
- 简体中文、繁体中文和日文目录必须保持全部条目已翻译且无 `unfinished`。
