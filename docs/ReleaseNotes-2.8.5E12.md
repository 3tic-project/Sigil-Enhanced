# Sigil-Enhanced 2.8.5E12 更新说明

发布准备日期：2026 年 9 月 27 日。正式发布日期以安装包发布为准。

本说明汇总 `v2.8.5E11` 之后至 E12 的改动。E12 标签和安装包尚未发布。

## Native Agent

- 对话中的用户消息和完整回答支持 Markdown。回答里提到当前书籍中真实存在的文件路径，以及明确对应的 XHTML 源码行号时，可以点击打开代码视图。跳转前会核对书籍会话、资源和原文；文件被删除或内容变动时不会盲跳旧位置。原始 HTML、图片和外部链接不会在对话卡片中执行或打开。详见 [Native Agent 使用说明](NativeAgent.md#markdown-答复与书内定位)。
- 新增校对候选扫描和审阅流程。`proof.audit` 对可见正文给出有界、分页的候选；用户可决定接受、忽略或待定，再生成计划、预览并提交。当前规则重点是异常字符和少量重复标点，候选不等同于已确认错字；跨标签内容仍需人工处理。
- 新增只读 `python.inspect`，用于对当前书籍做自定义统计。编辑仍使用 `python.run`，并遵守现有权限和事务规则。
- 搜索、资源和目录等工具增加分页或游标；资源文本修改区分资源修订与书籍修订，冲突时要求重读目标。文稿灌入工具可传自定义章节标题和插图标记规则。
- 调整模型请求历史，让系统提示、工具定义和开头的书籍映射保持稳定，便于提供商复用缓存前缀；上下文接近模型限制时使用有界检查点。
- Native Agent 设置新增“首次模型输出超时”，默认 180 秒。它从发起请求计时，直到收到推理、正文或工具输出；响应头和心跳不算输出。首次输出后仍按流空闲时间判断中断。
- OpenRouter 现在按模型支持的推理档位构造请求，并回放结构化推理详情；标题请求头改为 `X-OpenRouter-Title`。OpenCode Go 会识别只提供 `/responses` 或 `/messages` 的模型并明确提示当前客户端仅支持 Chat Completions。提供商和最近一次请求状态收进折叠的“技术细节”。

## 编辑与关闭书籍

- “编辑目录”现在可以选中多个条目并一次删除，撤销仍按一次操作恢复。
- 关闭 EPUB 时等待解压后的临时工作目录清理完成；清理失败会重试并记录警告，避免最后一个窗口退出过快导致目录全部或部分残留。强制终止进程不在这项修复范围内。

## 内部实现

- 一批内置 XML、OPF/NCX、元数据、文本编码、替换函数、静态 GIF 和更新订阅操作改为 C++ 实现，减少这些内置路径对嵌入式 Python 的依赖。第三方 Python 插件接口仍保留；对应迁移增加了与旧实现对比的测试。

## 验证与发布状态

- 临时目录清理、目录多选删除、Agent 对话定位、模型请求和底层迁移均有对应的自动化测试。本次发布准备还会重新编译应用并运行相关测试。
- 本说明对应准备中的 `2.8.5E12` 源码。Windows / macOS 安装包、签名和校验和按 [发布清单](ReleaseChecklist.md) 在最终提交和标签确定后生成。
