# 高级正则工作台使用说明

适用版本：Sigil-Enhanced 2.8.1E7 及以上。

高级正则工作台用于把多条 PCRE2 正则规则组成一个可保存、可试运行、可撤销的批处理方案。它除普通查找替换外，还支持二级正则筛选、递归替换、命名捕获变量和仅捕获规则。

## 快速开始

从 **增强 > 高级正则工作台...** 打开窗口，然后：

1. 在 **文件** 中选择作用范围。
2. 在 **规则编辑器** 中填写 **查找正则** 和 **替换文本**。
3. 点击 **试运行**，检查下方的 **试运行结果**。
4. 双击结果行，核对对应文件和位置。
5. 默认保留 **应用前创建恢复检查点**；若每个文件各自的撤销记录已经足够，可主动取消勾选。
6. 确认无误后点击 **应用**。

**试运行**不会修改 EPUB，也不会保存会话变量。**应用**会重新读取当前书籍并从头执行方案，不会直接采用上一次试运行的暂存结果。

工作台是独立的非模态窗口。打开后仍可切回 Sigil 编辑正文；再次从菜单打开会聚焦已有窗口。窗口标题会同步当前 EPUB 名称和修改状态。

## 界面说明

| 区域 | 控件 | 用途 |
| --- | --- | --- |
| 方案 | **新建**、**打开方案...**、**保存方案...**、**方案** | 管理整组规则。新建非空方案时会先询问是否清空现有规则。 |
| 规则 | **添加**、**复制**、**移除**、**上移**、**下移** | 管理规则及执行顺序。取消勾选规则可临时停用。 |
| 规则编辑器 | **名称**、**启用** | 设置当前规则名称和启用状态。 |
| 匹配表达式 | **二级模式**、**二级正则**、**查找正则**、**替换文本** | 定义候选范围、主匹配和输出。 |
| 规则选项 | 递归、零长度匹配、仅捕获、变量展开 | 控制规则的高级行为。 |
| 命名捕获 | **存储所有命名捕获组**、**捕获变量** | 决定哪些命名捕获组写入变量。 |
| 运行 | **文件**、**变量作用域**、**写入策略**、**应用前创建恢复检查点** | 设置本次运行的资源范围、变量行为和整书恢复策略。 |
| 运行按钮 | **试运行**、**应用**、**取消运行** | 预览、正式写入或取消当前计算。 |
| 变量 | **清空变量**及变量表 | 查看作用域、资源、名称和值。 |
| 试运行结果 | **规则**、**文件**、**行**、**替换前**、**替换后**、**迭代**、**变量** | 检查每个匹配及其变量变化。 |

规则编辑区由三栏组成，可以拖动分隔线调整宽度。

## 执行机制

一次运行遵循以下规则：

1. Sigil 先取得所选文本资源的内存快照，包括尚未保存到 EPUB 文件的编辑内容。
2. 规则按 **规则** 列表从上到下执行；每条规则依次处理目标资源。
3. 后续规则读取前面规则产生的内存文本，因此可以把复杂任务拆成多条简单规则。
4. 全部正则计算都在内存中完成。运行期间不会逐条规则写回、重载或渲染文档。
5. 暂存结果全部成功后，Sigil 检查 XHTML、OPF、NCX、SVG、XML 等 XML 文本的格式正确性。
6. **试运行**到此结束，不修改书籍或正式变量。
7. **应用**会在用户确认后重新执行上述步骤；若产生文本更改，默认先创建恢复检查点，再对每个变化资源写回一次。取消勾选 **应用前创建恢复检查点** 时会跳过整书检查点，但仍执行快照冲突检查，并为每个变化文件保留独立的撤销记录。

正则编译失败、变量未定义、递归不收敛、取消运行、XML 校验失败、启用时检查点失败或提交时资源已变化，都会丢弃整批暂存结果，不写入部分文本或变量。

整书处理或难以逐文件核对的替换建议保持检查点选项开启。跳过检查点只减少一次整书快照，不会关闭暂存校验、失败回滚或单文件撤销。

## 正则与替换语法

工作台使用 PCRE2。常用写法如下：

| 目的 | 写法 |
| --- | --- |
| 编号捕获组 | `(内容)` |
| 命名捕获组 | `(?<name>内容)` 或 `(?P<name>内容)` |
| 替换时引用编号捕获 | `\g{1}` |
| 替换时引用命名捕获 | `\g{name}` |
| 忽略大小写 | `(?i)表达式` |
| 让点号匹配换行 | `(?s)表达式` |
| 引用工作台变量 | `${var:name}`，并勾选 **在替换文本中展开 ${var:name}** |

`${var:name}`只在 **替换文本** 中展开，不会改写 **查找正则** 或 **二级正则**。变量值按普通文本插入，不会再次解释为捕获组引用。引用不存在的变量会使整次运行失败。

编辑 XHTML 时应避免让正则跨过不相关标签。涉及标签结构的批量替换应先选 **当前文件** 试运行，再扩大范围。

## 二级正则

**二级模式**有四种：

| 选项 | 机制 | 适用场景 |
| --- | --- | --- |
| **无** | 直接在整个目标文本中执行主正则。 | 普通查找替换。 |
| **预搜索范围** | 先用二级正则找外层范围，再在范围内执行主正则。二级正则有捕获组时使用第一个捕获组；没有捕获组时使用整个二级匹配。 | 只处理段落、对话或某个容器内部。 |
| **二级正则匹配时接受** | 先取得主匹配，再在每个主匹配文本内部执行二级正则；只有二级正则匹配的候选会被处理。 | 在主匹配结果中进一步保留目标。 |
| **二级正则匹配时拒绝** | 与上一项相反；二级正则匹配的候选被排除。 | 跳过包含 ruby、注释标记或特定词语的候选。 |

**预搜索范围**中的二级捕获组只决定范围，不写入变量。使用“匹配时接受”时，二级正则的命名捕获可以写入变量；它会先于主正则的命名捕获写入。

## 递归替换

勾选 **重复执行直到不再有匹配** 后，同一规则会在当前结果上反复查找替换，直到下一轮没有匹配。

**最大迭代次数**是硬上限。达到上限后仍有匹配、替换后文本与变量都没有进展、状态发生循环、文本增长过快或匹配数量超限，整条规则都会失败并恢复到运行前状态。

**允许零长度匹配**只在递归模式下可用，默认关闭。零长度规则容易产生无限增长，除非明确理解表达式的终止条件，否则不应启用。

## 命名捕获变量

变量来自主正则以及被接受的二级筛选正则中的命名捕获组。

- 勾选 **存储所有命名捕获组**：保存规则中所有命名捕获。
- 在 **捕获变量** 中填写 `name1, name2`：只保存允许列表中的名称。
- 勾选 **仅捕获变量（不替换）**：枚举匹配并保存变量，但不执行替换，不修改文本。

仅捕获规则必须启用 **存储所有命名捕获组**，或在 **捕获变量** 中至少填写一个实际存在的名称。仅捕获模式不能同时使用递归、零长度递归或替换变量展开。

### 变量作用域

| 选项 | 生命周期和可见范围 |
| --- | --- |
| **资源** | 每个 EPUB bookpath 有独立变量；适合同一文件内“先捕获、后替换”。 |
| **批次** | 本次运行的全部规则和全部目标资源共享；下一次运行前清空。 |
| **会话** | 成功点击 **应用** 后保留，可供工作台后续运行使用；关闭工作台或点击 **清空变量** 后清除。 |

**试运行**会在变量表中显示模拟结果，但不会发布会话变量。仅捕获方案即使不修改文本，也可以通过一次成功的 **应用** 发布会话变量；此时不会创建无意义的恢复检查点。

### 写入策略

| 选项 | 同名变量再次捕获时的行为 |
| --- | --- |
| **使用最后一个值** | 新值覆盖旧值。 |
| **保留首个值** | 第一次写入后忽略后续值。 |
| **追加值** | 按捕获顺序保存所有值；`${var:name}`读取最后一个值。 |

## 文件范围与结果定位

**文件**可选择：

- **当前文件**；
- **选中的文本文件（数量）**，来自 **图书浏览器** 当前选择；
- **所有 XHTML 文件（数量）**；
- **所有 CSS 文件（数量）**；
- **所有特殊文本文件（数量）**，包括 OPF、NCX、SVG、XML 和 MiscText；
- **所有文本资源（数量）**。

EPUB 3 Nav 属于 XHTML，因此包含在 **所有 XHTML 文件** 中。OPF、NCX 等特殊文件也会接受暂存 XML 校验。

双击 **试运行结果** 中的一行会打开对应资源并跳到记录位置。若资源内容仍与报告快照一致，Sigil 会高亮精确范围；如果该匹配由前一轮替换生成，或报告生成后资源已变化，则只跳到最接近的行，避免高亮错误文本。

报告行和片段有数量上限。超过上限时界面会提示省略行数，但匹配总数和替换总数仍然准确。

## 示例

以下例子中的字段名均对应中文界面。

### 示例一：把双线引号改为直角引号

原文：

```text
〝早上好〟
```

规则：

```text
二级模式：无
查找正则：〝([^〟]*)〟
替换文本：『\g{1}』
```

结果：

```text
『早上好』
```

### 示例二：只处理日文对话内部的双线引号

原文：

```text
「良〝聖女〟乙女早」
```

规则：

```text
二级模式：预搜索范围
二级正则：「([^」]*)」
查找正则：〝([^〟]*)〟
替换文本：『\g{1}』
```

二级正则的第一个捕获组限定在 `「」` 内部，因此结果为：

```text
「良『聖女』乙女早」
```

### 示例三：只替换包含指定词语的对话

原文：

```text
「聖女様、おはよう」 「今日は暑いね」
```

规则：

```text
二级模式：二级正则匹配时接受
二级正则：聖女
查找正则：「([^」]*)」
替换文本：『\g{1}』
```

二级正则在每个主匹配内部检查，只有第一句被接受：

```text
『聖女様、おはよう』 「今日は暑いね」
```

若改选 **二级正则匹配时拒绝**，则第一句保持不变，第二句被替换。

### 示例四：递归折叠全角空格

原文含有连续四个全角空格：

```text
段落甲　　　　段落乙
```

规则：

```text
二级模式：无
查找正则：　　
替换文本：　
重复执行直到不再有匹配：勾选
最大迭代次数：8
允许零长度匹配：不勾选
```

每轮把两个全角空格折叠为一个，最终只保留一个全角空格。

### 示例五：只收集角色名，不修改文本

原文：

```html
<span class="character">アリス</span>
<span class="character">ボブ</span>
```

设置：

```text
变量作用域：批次
写入策略：追加值
查找正则：<span class="character">(?P<name>[^<]+)</span>
仅捕获变量（不替换）：勾选
存储所有命名捕获组：勾选
```

**试运行**后，变量表会显示 `name` 的两个捕获值，正文与替换数保持不变。若需要跨后续运行保留这些值，把 **变量作用域** 改为 **会话**，再点击 **应用**。

### 示例六：同一文件先捕获章节名，再更新 title

原文：

```html
<title></title>
<h1>第一章</h1>
```

运行设置：

```text
文件：当前文件
变量作用域：资源
写入策略：使用最后一个值
```

规则一放在列表上方：

```text
名称：捕获章节名
查找正则：<h1>(?P<chapter>[^<]+)</h1>
仅捕获变量（不替换）：勾选
捕获变量：chapter
```

规则二放在其下方：

```text
名称：写入 title
查找正则：<title>[^<]*</title>
替换文本：<title>${var:chapter}</title>
在替换文本中展开 ${var:name}：勾选
```

规则二会读取规则一在同一资源中保存的 `chapter`，结果为：

```html
<title>第一章</title>
<h1>第一章</h1>
```

## 方案文件与自动执行

**保存方案...**会把当前配置保存为版本化 JSON。默认目录位于 Sigil 首选项目录的 `regex_workbench/` 下，保存采用原子写入。方案会记录规则顺序、二级模式、递归限制、变量设置和启用状态。

当前界面暂时隐藏 **导入搜索模板...**。已有搜索模板不会自动变成工作台方案；整条 Python `\F<函数名>` 替换也不受工作台支持。

在 **自动执行列表编辑器** 中可以使用：

```text
RunRegexWorkbenchRecipe 方案名称或绝对路径
```

名称可以是文件名（可省略 `.json`）、方案内显示名称或绝对路径。名称不唯一时会拒绝执行。自动执行固定处理当前 EPUB 的 **所有文本资源**，使用与界面相同的内存暂存、XML 校验、检查点和单次写回机制，但不会打开工作台窗口。

## 撤销、恢复与限制

- **试运行**永远不修改书籍。
- **应用**成功后，每个变化文件各有一个 **源码视图** 撤销步骤。
- 多文件整批恢复应使用应用前创建的恢复检查点；**源码视图**不提供跨文件的一次全局撤销。
- 运行中点击 **取消运行**，会在当前受限正则操作结束后取消，不发布部分结果。
- 工作台不支持整条 Python 函数替换、条件分支、只提交部分试运行结果或在查找表达式中展开工作台变量。
- 主正则和二级正则会预编译并在资源间复用；替换文本按匹配展开。匹配、递归、文本增长、变量大小和报告行数均有硬上限。
- 切换到另一本 EPUB 会取消并关闭旧书所属的工作台；运行期间继续编辑目标资源会触发冲突检查并拒绝旧暂存结果。

## 常见错误

| 提示 | 常见原因 | 处理方法 |
| --- | --- | --- |
| 暂存 XML 格式不正确 | 替换跨过标签边界，或把文本写入了标签名、属性名。 | 缩小到 **当前文件**，查看 **替换前/替换后**，收紧正则范围。 |
| 未定义变量 | 前置规则没有在当前作用域捕获该变量，或目标资源缺少匹配。 | 检查规则顺序、**变量作用域**、命名捕获和 **捕获变量**。 |
| 达到最大迭代次数 | 递归规则仍有匹配，或替换不断生成新匹配。 | 提高上限前先确认规则确实会收敛。 |
| 状态没有进展或进入先前状态 | 递归替换没有改变文本，或在两个结果间循环。 | 修改查找或替换，使每轮都朝唯一终态推进。 |
| 无法精确高亮 | 报告之后资源已变化，或匹配来自中间暂存文本。 | 双击跳到邻近行后人工核对。 |
| 所选作用域不包含文本资源 | 当前标签不是文本资源，或 **图书浏览器** 没有选中文本文件。 | 切换文件或重新选择 **文件** 范围。 |
