# Sigil-Enhanced 2.8.5E13 更新说明

源码发布日期：2026 年 10 月 31 日。安装包发布日期以发布页面为准。

本说明汇总 `v2.8.5E12` 至 `v2.8.5E13` 的改动。

## TXT 导出与窗口布局

- 新增内置插件「增强 → 导出 TXT 文件…」。按当前 OPF 的阅读顺序提取正文，包含尚未保存的编辑；未在 spine 中登记的 XHTML 附在末尾。保留标题、段落、显式换行、全角缩进、原文和译文，ruby 只保留基底文字，输出为无 BOM 的 UTF-8。支持图片替代文字和 SVG 文字，不执行 OCR。导出不修改 EPUB，也不改变未保存状态和撤销历史。详见 [TXT 导出说明](PlainTextExport.md)。
- 设置新增「记住上次窗口位置、状态和大小」，保存并恢复普通、最大化、全屏状态，以及面板、工具栏、编辑器分组和预览开发者工具布局。没有已保存布局或关闭此选项时，默认全屏启动。

## 编辑、搜索与插件修复

- 修复 Windows 临时目录清理代码的编译错误：长路径转换改为分别处理本地盘符路径和 UNC 网络路径，避免启用 Qt 快速字符串拼接后条件表达式类型不一致。
- 修复「编辑 → 撤销 → 重做」后界面已有修改，保存却提示没有更改的问题。保存 HTML 时不再重新载入文档，保留保存后的撤销、重做历史，并按最后保存的文本判断书籍是否修改。
- 查找/替换的重启会清除匹配缓存并移动到搜索范围的起点或终点；菜单入口连接到当前搜索模式。覆盖普通搜索、增强搜索和预搜索，以及正向、反向、当前文件、全书和标记区域，修复重启后只定位最后一项及标记区域越界的问题。
- 旧式插件直接覆盖图片等二进制资源时，通过运行前后的内容摘要识别实际修改，刷新资源并标记书籍需要保存。图片压缩插件处理后可以正常保存结果。
- BookLive 段落修正支持多层容器包裹、拆分正文和段落外的续行，保留全角空格、不换行空格等日文排版空白，修复部分正文未被识别为段落的问题。
- Code View 不再从已选文字内部启动文本拖动，避免 Windows 下相关崩溃；按下鼠标会重新开始选择。
- 临时工作目录被打开的文件、当前工作目录或插件只读文件占用时继续重试，并在退出时显示等待对话框。选择不等待退出后，下次启动继续清理；Live 插件物化的临时文件在插件进程释放后再删除。

## Native Agent

- 新增只读出版预检：对当前工作文本（含未保存及暂存修改）检查链接、资源、TOC、语言、图片替代文字和标题等问题，结果可分页，书籍变化后拒绝使用旧快照。部分路径大小写和语言属性问题可经审阅后暂存修复；图片 alt 使用编辑决定。预检不自动修改书籍，尚未接入 EPUBCheck/Ace。
- 新增结构诊断，按阅读顺序列出页面角色候选及证据、标题与目录的差异。删除仍被 TOC 引用的资源时会返回提示，便于同时修正导航。
- 增加在多个正文块之后批量插入译文或图注的能力，减少逐段调用。原稿解析支持带空白的特殊章节标题、目录中列出的章节及更多插图标记；放置图片时不再把文件名当作替代文字。
- Skill 元数据增加必需能力、触发词、显式名称和路由诊断；只提供当前模式允许且工具齐全的配方。新增只读的发行前预检配方，整书预检与结构扫描支持有界结果、缓存和取消。

工具说明及限制见 [Native Agent 使用说明](NativeAgent.md)，实施证据见 [Agent 能力审计](AgentCapabilityAudit_2026-09-30.md)。

## 验证与发布

- macOS Debug 完整编译通过。完整 CTest 与修正后的复测结果为 175 项通过、3 项因缺少 Cmoa 样例按设计跳过；片段工具栏集成测试显式使用宽屏普通窗口，以适配默认全屏启动。
- TXT 导出已通过正文提取、12,000 段长章节和真实 EPUB 2/3 菜单集成测试；另以三本真实 EPUB 的临时副本实测，覆盖原文、双语译本和 BookLive 格式，源文件未改动。
- 窗口布局、图片插件、BookLive 段落、撤销/重做、搜索重启和 Agent 功能均有对应的自动化回归测试。
- 版本号统一为 CMake `2.8.5E13`、更新订阅 `2.8.5.E13` 和标签 `v2.8.5E13`。标签推送后，由现有 CI 构建 Windows x64、macOS x64/arm64 安装包并生成校验和；构建结果以发布页面为准。
